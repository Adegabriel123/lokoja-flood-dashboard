# Source-data metadata

This folder is reserved for future metadata files (e.g. ISO 19115 records, data-quality reports, lineage statements).

The shapefile XML metadata for each layer is co-located with its source shapefile under:

- `source-data/flood/april/april21.shp.xml`
- `source-data/flood/july/juky15.shp.xml`
- `source-data/flood/november/nov2.shp.xml`
- `source-data/buildings/building.shp.xml`

The boundary and towns layers do not have `.shp.xml` metadata files in the source dataset.
